# ⚡ 01 — WHAT IS EDGEFLEET AI?

**EdgeFleet AI** is an Edge AI-powered autonomous fleet intelligence platform designed around a simple idea:

> **Give the system an environment. Let AI understand it. Let the fleet act on that understanding.**

The system works with a predefined or captured environment represented using a **linear X-Y coordinate system**.

The environment contains:

- 🧱 Walls
- ▣ Obstacles
- 🎯 Targets
- 🔋 Charging stations
- 🤖 Autonomous agents
- 📍 X-Y coordinates
- 🛣️ Planned routes
- 👁️ AI perception zones

The AI layer continuously processes this information to determine:

**WHERE → WHAT → WHY → HOW → NEXT**
